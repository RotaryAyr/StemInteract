How to use StemInteract.uk (quick guide)

Each topic page provides BBC Bitesize notes + past SQA Higher questions by topic + official SQA marking schemes + worked answer PDFs + optional AI strategy guidance. Use them in this order:

  1. Pick one weak topic (don’t jump about).
  2. BBC Bitesize first (5 minutes): skim key ideas, formulae and diagrams.
  3. Attempt a question (no notes, no AI):
    Calculations: equation -> substitution -> unit.
    Explanations: short, precise, mark-winning sentences.
    If stuck, think hard for a few minutes before seeking help.
  4. If needed: use AI for strategy hints only (not the full solution).
    Choose ChatGPT, Gemini or Claude from Ask AI. StemInteract opens the service and prepares the prompt where supported. If the prompt is not already shown, paste it from the clipboard. Then return and complete the question yourself.
  5. Mark with the official SQA scheme: tick the marking points you earned (method marks matter).
  6. Only then open the Answer PDF: correct in a different colour and rewrite the “ideal” answer if needed.
  7. Make an error log “fix rule”: what lost marks + what you’ll do next time (e.g. “Convert to SI first”, “State relationship before using it”, “Check powers of 10”, “Check signs/directions”).
  8. Do the next question in the same topic straight away. Repeat until mistakes reduce.
  9. When you’re scoring 70-80%, switch to timed practice and always check: units, signs/directions, powers of 10, sig figs.

Best routine: Bitesize -> Attempt -> (AI if stuck) -> Mark -> Fix -> Repeat.
